# M7 暂时不要继续堆东西

这一轮对 M7 的结果其实也很有价值，因为它帮我们排除了一个方向。

M7 做了：

\[
g=Dz
\]

的尺度变换，又做共同限速。

但报告发现把：

\[
D=I
\]

以后，尾段结果基本退化成 M6。

而原来的尺度版本同时改变了：

- 坐标尺度；
- \(B=JD\) 的奇异值；
- 阻尼；
- 实际物理反馈速度预算。

所以它不是一个干净的单因素改进。:chatgpt-content-reference{index="3"}

我建议现在：

\[
\boxed{\text{暂时冻结 M7。}}
\]

以后如果真要研究 scaling，单独做一篇清晰的 ablation：

\[
D=I
\]

vs

\[
D\neq I
\]

并确保实际物理控制预算相同。

否则现在会把研究主线搞乱。

如果导师要求一定要无噪声精度超过 VFCR，那我们还需要继续大改。

# 我现在最推荐的下一步：不要让 predictor 和 correction 共用同一个 \(\lambda\)

这是我读完这一轮报告以后觉得最值得做的改进。

现在 M5/M6：

纠错项：

\[
d_c
=
(J^TJ+\lambda I)^{-1}J^T\xi
\]

预测项也是：

\[
d_p
=
-(J^TJ+\lambda I)^{-1}J^T\widehat{\xi_t}.
\]

也就是说：

\[
\boxed{\text{同一个 }\lambda\text{ 同时承担两个完全不同的任务。}}
\]

但它们的需求其实相反。

纠错项面对状态误差和噪声，我们希望：

\[
\lambda_c>0
\]

增加鲁棒性、避免病态放大。

预测项面对的是：

\[
\dot g^*,
\]

它最怕的恰恰是阻尼把真实速度削掉。

所以我建议提出下一版 M8：

\[
\boxed{
d_c
=
(J^TJ+\lambda_cI)^{-1}J^T\xi
}
\]

但：

\[
\boxed{
d_p
=
-(J^TJ+\lambda_pI)^{-1}
J^T\widehat{\xi_t}
}
\]

其中：

\[
\boxed{
\lambda_p\ll\lambda_c.
}
\]

最终：

\[
\boxed{
\dot g
=
d_p
-
\gamma
\frac{d_c}
{\sqrt{\|d_c\|^2+\varepsilon^2}}.
}
\tag{M8}
\]

这个改法非常符合你们实验发现。

## 更进一步：prediction 根本不一定要用 Gauss–Newton

因为你们现在的：

\[
J
\]

是一个方阵。

理想根速度满足：

\[
\boxed{
J\dot g^*=-\xi_t.
}
\]

那理论上最直接的 predictor 应该就是：

\[
\boxed{
d_p=-J^{-1}\widehat{\xi_t}
}
\]

数值实现不要真的算 inverse，而是：

\[
\boxed{
Jd_p=-\widehat{\xi_t}
}
\]

用 QR / LU / SVD 解线性方程。

这比：

\[
(J^TJ+\lambda I)^{-1}J^T
\]

更接近理论公式。

如果完全无噪声，而且：

\[
J
\]

尚可解，我强烈建议先做一个**诊断版本**：

\[
\boxed{
d_p=-J\backslash\widehat{\xi_t}
}
\tag{M8a}
\]

但纠错仍然保留：

\[
d_c
=
(J^TJ+\lambda_cI)^{-1}J^T\xi.
\]

于是：

\[
\boxed{
\dot g
=
-J^{-1}\widehat{\xi_t}
-
\gamma
\frac{d_c}{\sqrt{\|d_c\|^2+\varepsilon^2}}.
}
\]

这个实验非常重要。

因为如果这样一改，M5/M6 尖峰瞬间明显消失，就可以几乎确定：

\[
\boxed{\text{之前剩余误差主要就是 predictor regularization bias。}}
\]

---

# 为什么这可能非常有效？

在准确根上：

\[
\xi=0.
\]

所以 correction 为零。

如果：

\[
\widehat{\xi_t}=\xi_t,
\]

而 predictor 用：

\[
d_p=-J^{-1}\xi_t,
\]

那么：

\[
\dot g=d_p=\dot g^*.
\]

于是理论上：

\[
\boxed{
\text{到达根以后，可以继续沿着根运动，而不是再次掉队。}
}
\]

这比目前：

\[
(J^TJ+\lambda I)^{-1}J^T\xi_t
\]

多了一层很关键的精确性。

报告给出的独立参考也验证了：

\[
\boxed{J\dot g_\delta^*+\xi_t=0}
\]

这一隐式微分关系，且参考速度和残差核验精度很高。:chatgpt-content-reference{index="6"}

所以这不是拍脑袋提出的新公式，而是直接来自移动根的隐式微分方程。

---

# 但直接 \(J\backslash \widehat{\xi_t}\) 有一个危险

就是：

\[
\sigma_{\min}(J)
\]

很小时，会放大差分噪声。

所以我建议不要一步就宣布它是最终模型。

先做三层实验：

\[
\boxed{\text{P1：直接解 }Jd_p=-\widehat{\xi_t}}
\]

\[
\boxed{\text{P2：极小 prediction damping}}
\]

比如：

\[
\lambda_p=10^{-10},10^{-9},10^{-8}
\]

\[
\boxed{\text{P3：SVD 截断 predictor}}
\]

对：

\[
J=U\Sigma V^T
\]

如果某个奇异值：

\[
\sigma_i<\tau,
\]

只对那个方向做限幅/正则化。

这样不是所有方向一起损失预测速度。

# 报告提出的“带上限 adaptive damping”也值得做

现在 M6：

\[
\lambda
=
\max(\lambda_{\min},
\kappa\sigma_{\min}^2).
\]

问题是：

普通时段 \(\sigma_{\min}\) 大的时候，

\[
\lambda
\]

反而可能变得很大。

报告已经发现 M6 的 \(\lambda\) 最大达到：

\[
0.0127,
\]

远大于 M5 的：

\[
10^{-6},
\]

所以平常时候的预测反而变差。:chatgpt-content-reference{index="7"}

报告建议：

\[
\boxed{
\lambda
=
\max
\left[
\lambda_{\min},
\min
\left(
\lambda_0,
\kappa\sigma_{\min}^2
\right)
\right]
}
\]

我认可这个方向。

取：

\[
\lambda_0=10^{-6}.
\]

这样：

- 正常时：
  \[
  \lambda\le10^{-6}
  \]
  不会比 M5 阻尼更大；

- 尖峰/病态时：
  \[
  \lambda\approx\kappa\sigma_{\min}^2
  \]
  又能保证最弱方向大部分保留下来。

不过我会再往前一步：

\[
\boxed{
\lambda_c
\text{ 和 }
\lambda_p
\text{ 分开设计。}
}
\]

这比“一个 capped lambda 管所有东西”更有研究价值。

# 还有一个现象现在应该暂时停止优化：原 QP 误差

你们现在 M5/M6/VFCR 对：

\[
x^*(t)
\]

的 RMSE 全都大约：

\[
5.064\times10^{-4}.
\]

这不是大家突然性能一样。

是因为：

\[
\boxed{\delta=10^{-4}}
\]

导致：

\[
x_\delta^*
\]

本身就离：

\[
x^*
\]

约这个量级。

:chatgpt-content-reference{index="8"} :chatgpt-content-reference{index="9"}

所以现在如果你继续把 tracking RMSE 从：

\[
10^{-6}
\]

压成：

\[
10^{-8},
\]

对原始 QP 的最终误差几乎不会明显改善。

下一阶段算法 tracking 做稳定之后，一定要开始扫：

\[
\boxed{
\delta=10^{-3},10^{-4},10^{-5},10^{-6}.
}
\]

然后画两种误差：

\[
\boxed{\|x-x_\delta^*\|}
\]

和：

\[
\boxed{\|x-x^*\|}.
\]

这能非常清楚地区分：

> solver tracking error

和

> PFB approximation error。
