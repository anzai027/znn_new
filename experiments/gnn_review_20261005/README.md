# GNN 复核实验（2026-10-05）

先阅读 [报告.md](C:/Users/anzai/Documents/znn_new/experiments/gnn_review_20261005/报告.md)。本文件夹保存独立新实验，旧模型和旧数据未修改。

99 组主要复跑已完成，另有公式核对、冻结题目、变化速度、增益、分块反例和尖峰加密诊断。运行环境为 Windows MATLAB R2025b。

在 MATLAB 中把本文件夹和需要的子文件夹加入路径：

- `run_review`：主要复跑，入口位于 rerun；已有结果会保留并跳过。
- `mechanism`：冻结题目、变化速度、增益和方向诊断。
- `audit`：公式诊断，入口位于 formula。
- `probe`、`speed`：分块反例和参考根速度，入口位于 m4。
- `dense`：尖峰附近加密输出；依赖已保存的独立参考速度诊断。
- `figures`：从新保存的数据重建比较图并检查文件。

各脚本会明确选择根目录和 v2 的模型程序；同时存在多个同名 experiments 函数时，请勿用 genpath 把整个仓库任意混入路径。更换模型、配置后应换输出目录，避免旧结果混入。

MAT 和 CSV 包含完整数据；FIG 可在 MATLAB 打开，PNG 可直接查看。主复跑的耗时只供记录，本次并行诊断不作为严格硬件速度排名。
