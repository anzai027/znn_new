# 参考根速度的独立复核

复核结论：完整状态的速度尖峰是真实的。第二版使用 0.005 秒网格得到的 141.07 只是粗网格中心差分估计，并非真实峰值上界。

父代理 `mechanism.m` 的 `velocities` 求导正确。固定状态 `g` 时，驻点部分的时间导数为 `dG*x+dh+dP'*mu1+dQ'*mu2`，等式部分为 `dP*x-du`，PFB 部分为 `(1-omega/sigma).*(dv-dQ*x)`；所以根速度满足 `J*dg+ft=0`。

本目录的 `speed.m` 独立采用两种求导方法：完整七维 PFB 方程，以及消去不等式乘子后的三维障碍 KKT 方程。设 `D=diag(delta./(2*slack.^2))`，则障碍 Hessian 为 `H=G+Q'*D*Q`，先用 `[H,P';P,0]` 求出 `dx/dt` 与 `dmu1/dt`，再用 `dmu2/dt=-D*(dv-dQ*x-Q*dx/dt)` 恢复不等式乘子导数。

完整 PFB 方程另外使用了有理化表达式，避免大数相减：`phi=(2*slack.*mu-delta)./(slack+mu+sigma)`。雅可比中的 `1-slack/sigma` 和 `1-mu/sigma` 也用等价有理式计算。此处理只用于参考解核对，没有改变 GNN 模型。

局部优化结果如下；这是在 3.4611 附近找到的局部峰，未宣称完成整个区间所有峰的全局优化。

直接重新求解相邻时刻的参考根，没有使用插值。中心差分步长为 `1e-8` 时，与障碍导数的相对差为 `2.8988e-8`；逐步缩小差分步长时误差先下降，再出现浮点舍入影响。这排除了插值和错误时间导数造成假尖峰的解释。

峰时 `x=[1.19975866871;1.19919090931]`，接近右上角 `[1.2;1.2]`。两个上界的松弛分别只有 `0.0002413313` 和 `0.0008090907`，两个对应乘子的速度分别是 `-3202.3616` 和 `952.5758`。变量 x 变化相对温和，但等式乘子与两个上界乘子正在快速重新分配。

题目所有系数都以 `2*pi` 为周期，因此这个局部尖峰在约 `9.74429445439` 秒再次出现。原聊天使用 0.005 秒网格，在 9.74 附近看到的速度约 141，遗漏了很窄的乘子变化过程。父代理复核中，0.005 秒网格的解析导数采样最大值为 113.44，中心差分最大值为 141.07；0.0005 秒网格解析采样最大值已升至 695.66；局部细化与优化给出 4735.71。

因此，把 gamma 从 100 提高至 200 或 300，可以减小误差，但仍不足以保证完整 g 在这个区间精确跟踪。这个结论不能直接套到单独 x：完整状态的巨大速度主要来自乘子。建议明确区分 x 的目标、乘子的目标、残差和约束违反量，再决定是否使用变量尺度、预测项或其他结构改动。
