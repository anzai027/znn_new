# 新 GNN 与原 VFCR-ZNN 的独立实验

在 MATLAB R2025b 中进入这个文件夹，执行 `run_compare`。
每组运行都会保存；再次执行会从尚未运行的组继续，不自动重跑已保存的失败组。
执行 `show_figures` 打开所有 MATLAB 图，或用 `show_figures('main_residuals')` 打开指定图。
已有数据时，执行 `run_compare(0)` 只更新汇总、图像和检查，不重新积分。

## 两个模型

VFCR 直接调用上两级目录的原 `my_system.m`，没有复制或改写。
本文件夹的 `gnn_system.m` 是根目录原文件的字节相同副本。
原文件 SHA-256 存在 `data/meta.mat`，运行前后检查，副本也检查。

VFCR 使用论文式（20）和（47），参数 `r1=r2=a=lambda1=lambda2=1`、`p=q=0.5`、NFTAF 激活函数。
新 GNN 使用已提出的 M1，主参数 `gamma=100,p=1`。
两者的 `delta` 均为 `1e-4`；VFCR 的 p 是激活函数指数，GNN 的 p 是梯度范数指数，不应混淆。

没有平滑激活函数，没有为分母添加小量，没有改写零梯度分支，没有到达阈值后冻结状态。
新模型传入的 problem 已删除 `dG,dh,dP,du,dQ,dv` 全部导数字段。
参考解和指标程序可以读取题目数据，但它们不向新模型提供系数导数。

## 题目和噪声

复用现有 Example 1、Example 2 的题目函数。
Example 1 用论文规定的 `1e8` 代替无限边界；Example 2 用 `1.2`。
等式遵循原题式（58）（59）：`sin(4t)*x1-cos(4t)*x2=cos(2t)`。
论文正文展示的 P 第二项写成正号，与题目约束不一致，本实验遵循题目和现有程序的负号。

Example 1 的初值由种子 1 顺序抽取，四个范围为 `[0,1],[0,10],[0,100],[0,1000]`。
Example 2 重新用种子 1 抽取 `[0,1]` 内的同一个七维初值。
VFCR 额外积分初值为零。

论文规定的六种噪声是常数 2、线性 0.1t、cos(t)、Gamma(1,1)、标准高斯、sin(8*pi*t+2)。
Gamma(1,1) 用指数分布等价公式 `-log(U)` 生成，不依赖统计工具箱。
随机噪声各分量独立，种子为 1～5，每 0.01 秒更新一次，区间内保持不变。
样本提前生成；积分在样本更新点分段，ODE 函数内部不调用 rand 或 randn。
种子、采样周期、求解器和容差是本实验的可复现补充，论文没有全部公布，不能声称逐像素复现。

论文入口组只运行 VFCR，噪声加在 `J*g_dot` 的右端。
共同状态噪声组将原 VFCR 内部噪声设为零，在两个模型的 `g_dot` 上加入同一噪声；VFCR 的 `z_dot` 不额外加噪声。
这个入口转换写在实验驱动函数里，原 VFCR system 保持不动，两组结果分开报告。

## 数值设置和失败记录

时间为 0～10 秒，输出间隔 0.005 秒，`ode15s`，`RelTol=1e-5,AbsTol=1e-7,MaxStep=0.02`。
精度检查为无噪声 Example 2 的 `RelTol=1e-7,AbsTol=1e-9`。
每组上限为 180 秒或者 500000 次 RHS 调用，先达到的生效。
计时只覆盖 ODE 求解，参考解、评价和绘图不计入。
用时重复为主参数的无噪声及余弦共同状态噪声，各三个重复。

`complete` 表示完整计算到 10 秒且输出有限。
它不代表求解正确，也不代表轨迹一定忠实于原微分方程。
`budget` 表示达到执行限额，`solver_failure` 表示 ODE 自己提前停止，`exception` 表示捕获到其他错误。
每组保留接受的原始时间点与状态、警告、异常编号和调用堆栈。
调用数包括触发限额时未实际计算导数的最后一次请求，因此限额记录可能显示 500001。
成功的共同输出网格由 `deval` 求得；中断网格只在已接受的点之间线性插值，绝不外推。
缺失的后续状态用 NaN，失败运行的收敛时间和 5～10 秒统计也用 NaN。
Inf 只用于完整轨迹没有满足持续达标判据，不与 NaN 混用。

## 两种参考解与指标

真正的最优解：把 `x=base+dir*alpha` 代入目标，得到区间上的一维凸二次函数，直接夹住无约束最优 alpha。
带 delta 的近似解：沿相同等式方向，最小化 `f(x)-(delta/2)*sum(log(v-Q*x))`。
其一维驻点用最多 80 次二分求解，再由 `mu2=delta/(2*slack)` 算乘子。
稳定的 PFB 恒等式只用于检验参考解；两个模型和共同残差指标使用原平方根公式，没有换算法。

记录状态、残差、与真解的距离、与 delta 解的距离、完整 g 与 delta 根的距离、梯度范数、雅可比最小奇异值。
另外记录等式、不等式、乘子非负和互补违反量、目标值和目标差。
相对真解和 delta 解的 RMSE、最大误差均使用 5～10 秒，RMSE 是二范数平方的均值再开方。
收敛时间是残差最后一次超过阈值之后的首个输出点，之后全程达标且剩余观察时间至少 0.5 秒。
阈值分别为 1e-6 和 1e-4；只在完整轨迹上计算，这是有限采样窗口判据，不是数学证明。
图像中零值仅在对数坐标上显示为 1e-16，原数据不改变。
中断图使用至多 512 个接受点展示误差，全部接受点保存在 MAT 中。

## p=1 的速度检查

新 GNN 在非零梯度处满足 `norm(g_dot)=gamma`，零梯度处沿用原程序的零速度。
状态噪声的范数若不超过 B，则任何真实轨迹都必须满足 `norm(g(t)-g(0)) <= (gamma+B)*t`。
无噪声时 B=0；确定噪声按公式取上界；随机噪声使用本组已保存样本的最大范数。
同时检查求解器接受点与输出网格，允许 `100*(AbsTol+RelTol*max(1,norm(g),norm(g0)))` 的宽松误差。
也检查相邻点的移动距离不超过速度上限乘以时间差，使用两端较大的误差允许量。
这个额外检查只排除明显不可能的轨迹，通过检查仍不能保证求解准确。
`tested` 表示适用此检查，`motion=0` 表示不通过，`motion=1` 表示未发现此类异常。
`excess` 是超出距离上限的最大值，`margin` 是再扣除上述误差允许量后的最大值。
每组的 `metrics.motion` 也分别保存接受点和输出网格的全程与相邻点超限值。
不通过的完整轨迹仍保留原始误差，但标为数值异常，不用其耗时宣布求解更快。
此检查只适用于新模型 p=1；VFCR 和其他 p 的 `motion` 为 NaN。
