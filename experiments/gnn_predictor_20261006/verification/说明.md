# 独立结果验收

验收没有重新运行 ODE，只读取保存的积分解，并重新计算指标和加密评估网格。入口为 `verify_results('data')`；网格细化与额外对照入口为 `verify_results('data','refine')`。

八组主结果均完整，运行时记录的源代码哈希与当前源文件一致。共同初值、题目源文件、时间点及配置一致，严格组只改变积分容差。各组 MAT 与汇总 MAT 的数值内容一致；保存轨迹通过积分器的 `deval` 完全重建。

独立重算的误差与原指标一致。时间加权 RMSE 使用 `sqrt(sum(diff(t).*(v(1:end-1).^2+v(2:end).^2)/2)/duration)`，与指标表最大差约 `2.84e-14`。不规则网格不能用各点误差的普通平均代替时间平均。

M7 的物理块速度最大值约为 `[100,3355.6,3340.3]`，均符合 `[100,5000,5000]`。共同 alpha 的重建误差为零，乘在预测与反馈总方向后的相对方向误差不超过 `3.03e-16`。实际接受轨迹及密集评估轨迹也通过相应速度界的数值容差检查。

指标里的 `limited=34` 是限速采样点数，不是时间比例。按时间积分限速指示量得到约 `0.01675` 秒，占 0～10 秒的 `0.1675%`；5～10 秒尾段没有触发限速。这是根据采样网格得到的持续时间估计。

严格组和主组的尾段 x 轨迹差 RMSE 约为 `1.4e-9`～`1.5e-9`，完整状态差 RMSE 约为 `3.0e-9`～`3.3e-9`。这些差异远小于观察到的模型误差；当前主要差异不能解释为积分容差不足。

把评估网格进一步并入 0.00025 秒网格后，共评估 49837 点。x 与 delta-x RMSE 的相对变化不超过 `2.52e-5`，完整状态 RMSE 相对变化不超过 `7.55e-4`，支持当前报告的误差量级。

稀疏采样可能严重遗漏峰值。M5 在 0.005 秒网格上的完整状态误差峰只有约 `6.33e-6`，密集网格却为 `0.09683`；残差峰从稀疏的约 `1.84e-7` 升为密集的 `1.96e-4`。因此，稀疏曲线不能支持持续高精度跟踪的判断。RMSE 也不会必然随加密而增大：稀疏梯形积分有时反而把一个窄峰扩展到较长区间，造成平均误差高估。

新结果与旧报告的真实 x RMSE 约 `0.000506`/`0.000492` 的差别主要来自统计口径。扰动参考根本身的偏差，在密集时间加权口径下为约 `0.00050644`，在旧 0.005 秒网格普通均值口径下为约 `0.00049255`；0.005 秒网格时间加权口径约为 `0.00049278`。M7 用旧普通均值口径得到约 `0.00049253`，新密集时间加权口径约为 `0.00050641`，不能把两者直接解释为算法退步。

额外对照的指标也已独立复算。M6 把 kappa 从 0.05 降至 0.01 后，delta-x RMSE 约为 `2.4065e-6`，完整状态峰误差约为 `0.0024052`。M7 使用单位尺度后，尾段结果与 M6 基本一致；共同限速依然只作用在初始约 `0.01675` 秒。这支持将阻尼、变量尺度与初始限速分别讨论。

数值见 `integrity.csv`、`sampling.csv`、`limits.csv`、`precision.csv`、`refinement.csv`、`bias.csv`、`extra.csv`；对应完整验收结果见 `results.mat` 和 `refinement.mat`。
