# 独立参考解

`pp_reference(t,p,delta)` 接受规则或不规则的时间点，并保持输入点的顺序。适用范围为二维变量、一条满行秩等式、四条有限不等式，且目标沿可行方向严格凸。参考函数使用题目的解析导数；这些导数只用于验证参考轨迹，不能作为预测模型的输入。

原 QP 解 `x` 由等式可行直线上的一维二次函数和区间投影独立求出。扰动解 `xd` 由同一可行区间内的障碍驻点方程二分求出，满足 `slack.*mu=delta/2`。参考根不是任何神经模型的运行结果。

主要字段为：

| 字段 | 含义与尺寸 |
|---|---|
| t | 输入时间，N×1 |
| x | 原 QP 的真实最优解，N×2 |
| xd | delta 扰动解，N×2 |
| g | 完整扰动根 `[xd;mu1;mu2]`，N×7 |
| velocity | g 的解析时间导数，N×7 |
| speed | 完整 g 的速度范数，N×1 |
| sigma | 稳定完整 PFB 雅可比的最小奇异值，N×1 |
| bias | `norm(xd-x)`，N×1 |
| error | 稳定完整 PFB 残差范数，N×1 |
| f、fd | 原解和扰动解的目标函数值，N×1 |
| slack | 扰动解的四个正松弛量，N×4 |
| check | 原等式、扰动等式、驻点、不等式和 PFB 检查，N×5 |
| derivative | 三维障碍与七维 PFB 导数的相对差，N×1 |
| identity | 隐式微分方程 `J*velocity+ft` 的相对残差，N×1 |

`velocity` 是完整扰动根的导数，不是原 QP 在活动约束切换处可能不连续的乘子导数。

速度使用两种方法交叉检查。消去不等式乘子后，令 `D=diag(delta./(2*slack.^2))`，障碍 Hessian 为 `H=G+Q'*D*Q`。三维障碍 KKT 求出 x 和等式乘子的导数，再恢复不等式乘子导数；完整七维方程则通过 `-J\ft` 求导。PFB 残差和雅可比都使用等价有理式，避免接近零时的大数相减。

`reference_check` 已通过少量点、周期重复、向量 delta、空时间输入及中心差分核验。最大参考残差约 `5.82e-14`，两种速度的最大相对差约 `1.24e-15`。

局部峰时间约 `3.4611091472`，完整速度约 `4735.7083211`，与上一轮独立复核一致；中心差分步长 `1e-8` 时的相对差约 `2.72e-8`。这些高速度主要来自乘子重新分配，而不是 x 的速度。

另对 27989 个不规则时间点进行了密集核验，包含全区间和两处尖峰附近的细化点。MATLAB R2025b 用时约 1.85 秒，最大参考残差 `3.96e-12`、两种速度的最大相对差 `6.11e-15`、隐式微分恒等式最大相对残差 `1.54e-13`；结果保存在 `reference_dense.mat`。
