# GNN 与 VFCR 的平滑补充试验

在 MATLAB 中进入本文件夹，运行 `run_smooth`；已有逐组数据会保留并跳过，运行 `show_figures` 打开全部 FIG，运行 `regenerate` 只重建图像和报告。

原 VFCR 直接调用仓库根目录的 `my_system.m`，通过其已有的 `problem.phi` 入口提供平滑激活函数，不修改原文件。

`gsmooth.m` 由原 GNN 生成，唯一公式改动是分母从 `r^p` 改成 `hypot(r,eps)^p`，没有读取系数导数或新增状态。

`fsmooth.m` 只在 `abs(x)<eps` 内替换激活函数，使用奇三次多项式，使边界的函数值和一阶导数连续；区间外保持原式。

尺度扫描为 `1e-4、1e-3、1e-2、1e-1`；预先指定 `1e-3` 为补充检查主尺度。GNN 与 VFCR 的尺度作用于不同量。

初次安排 38 组：Example 2 无噪声/共同余弦噪声四尺度 16 组，Example 1 初值范围 1 两组，Example 2 严格容差两组，共同高斯噪声五种子十组，主尺度三次计时追加八组。

扫描发现 1e-3 的 GNN 无噪声未完成，因此追加 1e-2 的同样 22 组补充检查，总共 60 组；1e-2 是依据扫描选择的探索设置，所有尺度和失败仍完整保留。

题目、初值、参考解和噪声样本复用 `../gnn_vfcr_20261002/data`；原公式基线也读取该目录的保存数据，运行后检查四个原文件 SHA-256 未改变。

结果统一在 `data`，图像在 `figures`，运行日志在 `logs`，中文结论在 `结论.md`。

平滑版改变了数学公式，目的是检查数值中断能否缓解，不能视作原式严格复现或原有限时间理论的验证。
