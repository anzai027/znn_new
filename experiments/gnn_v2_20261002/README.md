# 第二版 GNN 实验

在 MATLAB R2025b 中进入本文件夹，运行 `run_v2`；已有逐组 MAT 会读取并校对设置，运行 `run_v2(35)` 可以只尝试前 35 组机制扫描。

新模型程序为 `pg_system.m`，说明见 `模型说明.md`。原始 GNN、VFCR 直接调用仓库根目录现有程序，不修改、不复制原 VFCR。

M1 为原 GNN，M2 为平滑旧 GNN，M3 为阻尼预条件 GNN，M4 为预条件加分块速度；M3/M4 均包含平滑和不平滑版，VFCR 与 VFCR-S 分别是原激活函数与平滑激活函数对照。

先做 Example 2 无噪声的 35 组机制诊断：阻尼 1e-6/1e-4/1e-2、平滑尺度 1e-3/1e-2、统一增益 100/150/200/300，分块设置包含相同总速度上限对照。原 M1 无噪声异常轨迹沿用旧保存数据，标为 reused，不重复作可信计时。

主参数预先设为 lambda=1e-6、eps=1e-2，M2/M3 gamma=200，M4 rates=[100,200,200]；后续测试原六种噪声和随机种子 1～5、无噪声/余弦三次计时、严格容差和 Example 1 四组初值，共 164 次尝试。

按用户补充要求，M3/M4 另外将 eps 设为零，重复机制、全部共同噪声、三次计时、严格容差、四种初值和大边界诊断；重复的零尺度扫描合并，新增 64 组，总共 228 组。MAT/CSV 中明确保存 smooth 标记，零点取零速度，不加分母小量。

时间、输出网格、容差、步长上限、噪声入口、离散化和每组预算沿用旧实验。所有模型共用初值和预生成的噪声，随机噪声按 0.01 秒分段积分，不在 RHS 内重新抽样。

指标包括两种参考解误差、完整状态误差、残差、约束违反、梯度、方向范数、最小奇异值、控制速度、参考轨迹速度、持续达标时间、运行时间、调用次数与失败记录。NaN 代表缺失，Inf 代表完整运行未持续达标。

`data` 保存逐组 MAT、汇总 all.mat、metrics.csv 和参考解；`figures` 保存 FIG/PNG，运行 `show_figures` 打开全部图；`logs` 保存 MATLAB 日志；`sources` 保存建议原文；中文结论在 `结论.md`。
